# Changesets

改了 SDK 就跑一次 `npx changeset`：选改了哪几个包、升哪一级，再写一两句「这次改了什么」（中文照写，会原样进 CHANGELOG）。
生成的 `.changeset/*.md` 跟着代码一起提交。

升哪一级（包都还在 0.x）：
- **patch**（0.4.0 → 0.4.1）：修 bug、改文档、内部重构，舞台作者什么都不用改。
- **minor**（0.4.0 → 0.5.0）：加了新能力，或者有任何需要舞台作者跟着改的地方。

★加了新的桥协议请求（比如 0.4.0 的 `stage.speak`）：网站要先上线支持，SDK 才能发版（平台先上、SDK 后发）。

推到 main 以后，GitHub 会自动开一个「发版」PR，把版本号和 CHANGELOG 都算好；合并它才真正发布到 npm。
